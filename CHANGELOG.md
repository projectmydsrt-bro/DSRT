# Changelog

All notable changes to DSRT.js will be documented in this file.  
This project adheres to [Semantic Versioning](https://semver.org/).

---

## [Unreleased]

### Added
- New interactive hero background types: WaveGrid, Nebula, Particles  
- Orbit and Pan camera controls for demo scenes  
- Sample meshes: Torus, TorusKnot, Custom Geometry  
- Neon, Metallic, Bloom, Fog post-processing effects  
- DSRT.js `onError()` handler for error recovery  
- Collab CTA component for GitHub linking  

### Changed
- Updated README badges for build, license, version, stars, forks  
- Improved responsive layout for Next.js landing page  
- Refactored DSRT.js init and mesh system for performance  

### Fixed
- Bug with mesh rotation animation in fullscreen canvas  
- Issue with background load failing on mobile devices  
- Minor UI glitches in demo components  

---

## [1.0.0] – 2025-09-17

### Added
- Initial release of DSRT.js Next-Gen 3D Web Engine  
- Fullscreen 3D hero canvas with background  
- Mesh creation system: cube, sphere, cylinder, cone  
- Basic lighting system: point, directional, ambient, spot  
- Interactive demos with hover, click, drag  
- Full landing page in Next.js with docs section  
- LICENSE (MIT), CONTRIBUTING.md, CODE_OF_CONDUCT.md, SECURITY.md  

### Fixed
- Initial build and CI setup for GitHub Actions  

---

## [0.1.0] – 2025-09-10

### Added
- Prototype DSRT.js engine in vanilla HTML/JS  
- Sample background and cube mesh  
- Basic rotation animation  
- Initial README and placeholder docs
